# Saved versions of the card pool

Before each change to the card pool, the version being replaced is saved here as a dated copy of
`data/card-pool.md`, and its commit is tagged `card-pool-<date>-<name>`, so the whole repo at that
point (card data, binders, faces, table) can be brought back with `git checkout <tag>`.

| File | Tag | What it is |
| --- | --- | --- |
| `card-pool-2026-11-08-third-pass.md` | `card-pool-2026-11-08-third-pass` | The third pass as of Nov 8, 2026 (100 cards: Gap cut, Origin at #100, Archipelago at 10 water), before the restructure by ring count. The playtest table and simulator still use it. |
